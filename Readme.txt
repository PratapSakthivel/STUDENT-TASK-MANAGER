# Student Task Manager

Student Task Manager is a small application for managing academic and personal study tasks.

## Project Goal

The goal of this project is to build a simple real application while learning and practicing:

- Java
- Spring Boot
- Spring Data JPA
- SQL
- HTML
- CSS
- Git and GitHub

The project is intentionally kept small so that the application structure, development process, and Git/GitHub workflow can be understood clearly.

## Technology Stack

- **Backend:** Java, Spring Boot
- **Data Access:** Spring Data JPA
- **Database:** SQL / MySQL
- **Frontend:** HTML and CSS
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## Project Scope

The application will eventually support:

- Creating tasks
- Viewing tasks
- Updating tasks
- Deleting tasks
- Changing task status

The application will be developed gradually through separate project phases.
